# Upload Instructions for v2.4

This version fixes duplicate sidebar navigation and adds visible publication timestamps to projects, notes, publications, and CV pages.

Upload the CONTENTS of this folder to the root of your GitHub Pages repository, not the folder itself.

Required root-level files:

- index.html
- style.css
- script.js
- publications.html
- notes.html
- cv.html
- projects/
- notes/
- assets/

After uploading, commit changes and visit:

https://yuanyang0806.github.io/

If the old page appears, press Ctrl + F5.
