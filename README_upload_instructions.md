# Yuanyang Liu Personal Homepage v2.3

This version fixes navigation among Home, Projects, Publications, Notes, and CV.

## Upload instructions

1. Unzip this package.
2. Open the folder `personal_homepage_v2_3_fixed_nav`.
3. Upload the files and folders inside it to the root of your GitHub repository `Yuanyang0806.github.io`.
4. Make sure `index.html` is in the repository root, not inside another folder.
5. Commit changes.
6. Visit: https://yuanyang0806.github.io/

## Important

If your homepage shows a project page, it means your root `index.html` was overwritten by a project detail page. Replace it with the `index.html` in this package.
