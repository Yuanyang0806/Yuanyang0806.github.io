# Personal Homepage v2.1

这是给 `Yuanyang0806.github.io` 准备的 v2.1 个人主页文件。

## 如何上传

1. 解压这个 zip。
2. 在 GitHub 仓库 `Yuanyang0806.github.io` 中：
   - 替换 `index.html`
   - 替换 `style.css`
   - 替换 `script.js`
   - 新增 `notes.html`
   - 新增 `publications.html`
   - 新增 `cv.html`
   - 新增 `projects/` 文件夹里的页面
   - 新增 `notes/` 文件夹里的页面
3. 保留你原来的 `avatar.jpg`。
4. 如果要启用 PDF CV，上传文件到 `assets/cv.pdf`。
5. Commit changes 后，等待 GitHub Pages 自动部署。

## 维护建议

- 首页只放浓缩信息。
- Projects 里面放系统和代表项目。
- Notes 里面放技术博客、论文阅读和实验复盘。
- CV 里面放教育经历、技能、项目、论文、奖项。
